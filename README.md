# ChemistryHub — النسخة النهائية

## الموجود في هذه النسخة
- لوحة إدارة كاملة بدون تعديل ملفات المصدر.
- إدارة الفرق الأربع.
- إضافة/تعديل/حذف المواد داخل كل فرقة وفصل.
- رفع PDF لكل مادة إلى Supabase Storage وحذف/معاينة الملفات.
- إنشاء وتعديل وحذف الاختبارات والأسئلة والاختيارات والإجابة الصحيحة.
- خدمات الموقع قابلة للإضافة والتعديل والحذف مع خيار طلب تسجيل الدخول.
- إعلانات وأخبار من لوحة الإدارة.
- التحكم في نصوص الصفحة الرئيسية وروابط التواصل والمساعد الذكي.
- إدارة المستخدمين والصلاحيات.
- المحتوى الأكاديمي العام يمكن استكشاف أسمائه للزائر، بينما الملفات والاختبارات وGPA تتطلب تسجيل دخول.

## التشغيل
1. ارفع الملفات إلى Vercel كما هي.
2. افتح Supabase > SQL Editor والصق كامل `supabase.sql` وشغله مرة واحدة.
3. اجعل حسابك مديراً: `update public.profiles set role='admin' where email='بريدك';`
4. افتح `admin.html` وسجل الدخول.
5. من لوحة الإدارة أضف المواد والملفات والاختبارات والخدمات والإعلانات.

## ملاحظة مهمة
لا تضع service_role key في الموقع. الملف `supabase-config.js` يحتوي المفتاح العام anon فقط.
