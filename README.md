# ChemistryHub

قالب موقع تعليمي لطلاب كلية التربية - قسم الكيمياء، مستوحى من فكرة بوابات الطلاب التعليمية الحديثة.

## الملفات

- `index.html` الصفحة الرئيسية وكل الأقسام.
- `css/style.css` التصميم المتجاوب والوضع الليلي.
- `js/data.js` جميع بيانات الفرق والمواد.
- `js/app.js` التفاعل، اختيار الفرق، وحاسبة GPA.
- `assets/` ضع فيها الصور واللوجو والملفات.

## التعديل

ابدأ من `js/data.js` لإضافة مواد الفرق 2 و3 و4.

ثم عدّل:
- اسم الموقع في `index.html`
- الألوان في `css/style.css`
- روابط المحاضرات والـPDF
- بيانات المواد والمدرسين
- أسئلة الاختبارات

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو ارفع المجلد كما هو على أي استضافة Static مثل Cloudflare Pages أو GitHub Pages.

## ملاحظة

هذا مشروع أصلي كنقطة بداية وليس نسخة من ملفات أو كود الموقع المرجعي.
