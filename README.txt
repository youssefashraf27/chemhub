ChemistryHub - ملفات الشات المنفصلة

الملفات:
1) chat.html
2) chat.js
3) chat.css
4) chat.sql

طريقة التركيب:
- ضع chat.html وchat.js وchat.css بجوار ملفات الموقع الحالية.
- لا تستبدل app.js أو auth.js أو style.css.
- افتح Supabase > SQL Editor وشغّل chat.sql مرة واحدة.
- chat.html يعتمد على الملفات الموجودة أصلًا في موقعك:
  supabase-config.js
  auth.js
- لفتح الشات مباشرة:
  chat.html

إضافة زر الشات لاحقًا:
